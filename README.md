# ACAI-PAY

Projeto desenvolvido como parte de uma atividade acadêmica, com o objetivo de implementar um sistema simples de conta digital utilizando Python.

## Descrição

O ACAI-PAY busca simular operações de uma conta digital, colocando em prática os conhecimentos adquiridos durante o desenvolvimento do trabalho.

## Tecnologias utilizadas

- Python
- Pytest
